# Piggy Bank motion preview

Standalone local HTML/CSS/JS animation, with a seamless 12-second loop. Open index.html directly, or serve this folder with a local HTTP server. No build step or external dependencies.

The goal, income, and expense cards are faithful raster crops of the supplied app screenshot. The money illustrations are crops of the supplied Money Attributes.png. The pig is the existing app asset. Figures are static illustrative content; this preview does not connect to app data.

Pause/play, restart, timeline, and clean-background view are included. Escape restores the controls. Reduced-motion preference starts the preview paused. The composition adapts to narrow screens.

Only this new folder was created. No production app/landing files were changed; nothing was committed, pushed, or published.
