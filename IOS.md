## Установка и сборка

Требуются Node.js 22+, pnpm 11.25.0, полный Xcode 26+ и установленный iOS Simulator runtime.
Официальные требования: https://capacitorjs.com/docs/getting-started/environment-setup

1. Установить Xcode из App Store, открыть его, завершить первоначальную настройку и загрузить iOS Simulator runtime. В Xcode → Settings → Locations выбрать Command Line Tools для установленного Xcode.
2. Из корня репозитория выполнить:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm ios:build
pnpm ios:open
```

`ios:build` синхронизирует ресурсы и вызывает `xcodebuild` для Debug-сборки симулятора без подписи. Результат при успешной сборке: `.build-ios/Build/Products/Debug-iphonesimulator/App.app`. Это приложение для симулятора, не IPA для физического устройства.

Проект: `ios/App/App.xcodeproj`, схема `App`, Swift Package Manager. Выбрать доступный iPhone Simulator в Xcode и нажать Run. После изменения HTML запускать `pnpm ios:sync` перед повторной сборкой.

Для физического iPhone отдельно выбрать команду подписи в Signing & Capabilities. Для TestFlight нужны настройка Apple Developer/App Store Connect и архивная подписанная сборка — они пока не выполнялись.

Тестовый bundle ID: `com.moneyplayground.preview`. Перед публичным релизом согласовать постоянный ID. Изменение ID создаёт отдельное приложение с отдельным хранилищем — не менять его после ввода важных данных без плана переноса.

## Данные и границы этой тестовой версии

Текущая логика localStorage намеренно сохранена для первого сравнения. Не считать её окончательным надёжным хранилищем финансовых записей: перед использованием реальных данных нужны отдельное постоянное хранилище/резервирование и проверенный перенос.
Записи Safari автоматически в WKWebView не появляются. Экспорт/импорт, Supabase, авторизация и синхронизация этим изменением не реализованы. В тестовой сборке использовать тестовые записи; браузерные данные не удалять.

Уведомления остаются отложенными согласно NOTIFICATIONS.md. Monthly Recap не включался; его скрытый экспорт PDF/XLSX не адаптировался для iOS. Гарантировать полное совпадение работы до прохождения проверки на iPhone нельзя.

## Автозапуск на этом Mac

По запросу пользователя включено компактное окно Device Hub и автозапуск при входе в учётную запись macOS.
LaunchAgent: `~/Library/LaunchAgents/com.moneyplayground.simulator.plist`.
Рабочий скрипт и журналы находятся в `~/Library/Application Support/Money Playground/`.
Копии конфигурации и скрипта для обслуживания: `mobile/com.moneyplayground.simulator.plist` и `scripts/start-iphone-preview.sh`.
Скрипт запускает существующий симулятор iPhone 18 Pro и установленное приложение; не стирает данные и не переустанавливает сборку. Проверочный запуск launchd завершился с кодом 0. Полный выход/вход в macOS не выполнялся.

Отключение: `launchctl bootout "gui/$(id -u)/com.moneyplayground.simulator"`, затем переместить соответствующий plist из `~/Library/LaunchAgents/` в другую папку. После сна уже открытое окно остаётся; отдельный запуск на каждом пробуждении не настроен.

## Полноэкранная компоновка iOS

`mobile/native-layout.css` подключается только в мобильный пакет после стилей исходного макета. Он убирает стандартный отступ body, внешние отступы контейнера, ограничение ширины 402px, уменьшение высоты на 32px, скругление и тень внешней рамки. Фон занимает весь экран, safe-area остаётся у контента и нижней навигации. Карточки и кнопки сохраняют своё оформление. Канонический HTML и веб-версия не меняются.

Полноэкранная сборка повторно собрана и установлена в iPhone 18 Pro; светлые поля внутри экрана исчезли. История с тестовыми 12 EUR сохранилась после обновления. Дополнительные проверки геометрии onboarding и основного контейнера прошли на 375×667, 390×844 и 430×932.

## Утверждённый splash screen — 16 ноября 2026

`mobile/splash/` подключается при каждом холодном запуске мобильного приложения. Пружинка и звезда — отдельные прозрачные PNG; анимация длится около 1,9 секунды и плавно открывает приложение. Возврат из фона не перезапускает заставку. Уменьшение движения учитывается; резервный таймер удаляет заставку через 2,3 секунды. Статический системный LaunchScreen использует тот же размер 168 pt и чёрный фон. Веб-версия не затрагивается.
