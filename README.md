# My Money Playground

Интерактивные прототипы в выбранном стиле Peach Club. Это концепции интерфейса, не нативное iPhone-приложение. Введённые данные не сохраняются между сеансами.

- `onboarding.html` — текущая версия: выбор цели или пропуск, план месяца и готовая копилка. Включает объёмные кнопки выбора, подмигивающую свинку, анимацию монетки и переключатель звука. Откройте файл в браузере; иконки загружаются из сети.
- `source/piggy-onboarding.html` — редактируемый исходный фрагмент текущей версии; изображения, используемые на экране, встроены в файл.
- `assets/` — исходные и уменьшенные изображения свинки для текущей версии.
- `index.html` — предыдущий прототип экрана «Моя копилка», сохранён без изменений.
- `source/piggy-bank-plan.html` — исходный фрагмент предыдущего прототипа.
