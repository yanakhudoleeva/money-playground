# My Money Playground

Интерактивный прототип My Money Playground для просмотра на телефоне. Это веб-приложение, а не нативное iPhone-приложение.

Текущая сохранённая версия соответствует опубликованной версии Sites 82 (исходный коммит Sites `58a4d3f9cc04d1fd98d85e8a06e081c09addfd4e`).

- `onboarding.html` и `dist/index.html` — опубликованная сборка приложения: выбор цели, план месяца, копилка и My Spending. Шаг с доходом и расходами можно пропустить и заполнить позже.
- `piggy-onboarding.html` и `source/piggy-onboarding.html` — исходный фрагмент текущего приложения.
- `assets/` — изображения свинки; `dist/` также содержит лицензии встроенных библиотек.
- `.openai/hosting.json` — настройки исходного проекта Sites.
- `index.html` и `source/piggy-bank-plan.html` — предыдущий прототип, сохранённый для истории.

My Spending использует хранилище браузера, доступность и сохранность которого зависят от среды просмотра. Данные плана не являются облачной резервной копией. Иконки и шрифты могут загружаться из сети.
