# My Money Playground

Интерактивный прототип экрана «Моя копилка» в выбранном стиле Peach Club. Включает логотип со свинкой, жильё, ежемесячные расходы, настраиваемые категории и прогноз накоплений.

- `index.html` — самостоятельная версия прототипа. Откройте файл в браузере.
- `source/piggy-bank-plan.html` — исходный редактируемый фрагмент прототипа.

Это прототип интерфейса: данные в нём демонстрационные и не сохраняются между сеансами. Нативное iPhone-приложение ещё не создано.
